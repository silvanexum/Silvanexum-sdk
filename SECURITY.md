# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately, either:

- through GitHub: **Security → Report a vulnerability** on this repo, or
- by email to **ceo@silvanexum.com** with "SECURITY" in the subject.

Include what you found, how to reproduce it, and which package and version it
affects. You'll get a reply within 3 working days. We'll keep you updated while
we fix it and credit you in the release notes if you'd like.

## Scope

This repo contains client code: the SDKs, the MCP server, the NVIDIA plugins,
the VS Code extension and the Claude skill. Issues in the hosted Silvanexum
service (api.silvanexum.com, silvanexum.com) are also welcome through the same
channels.

## Supported versions

Security fixes go into the latest release of each package.
